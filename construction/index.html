Construction & Layout Editor — Floor Plans, HVAC Maps & Architectural Drawings

Draft room layouts, floor plans, HVAC ductwork maps, and architectural drawings in your browser. Purpose-built symbol library for walls, doors, windows, fixtures, and mechanical systems. Supports both metric (mm, cm, m) and imperial (in, ft) coordinate systems. No AutoCAD license, no install required.

What you can design

  • Room layout and floor plan diagrams with accurate wall and door placement
  • HVAC ductwork routing maps for residential and light commercial systems
  • Architectural elevation drawings with dimension annotations
  • Furniture and fixture placement layouts for interior planning
  • Site plans with property boundaries, setbacks, and utility paths
  • Fire egress and safety exit maps with emergency symbol sets

Measurement and grid support

  • Metric grid: millimeters, centimeters, meters with snap-to-grid precision
  • Imperial grid: inches and feet with fractional snap increments
  • Scale ruler overlay for real-world dimension reference
  • Dimension annotation tool auto-calculates lengths from placed elements

Export options

  • SVG — clean vector output for printing or web embedding at any scale
  • PNG — rasterized export at configurable DPI
  • JSON — full scene graph for re-import or programmatic processing

Frequently asked questions

Can I switch between metric and imperial mid-drawing?
Yes. The unit system can be changed at any time from the canvas settings panel. Existing element dimensions are recalculated automatically.
Is this a replacement for AutoCAD or Revit?
No — it’s a lightweight browser-native drafting tool for early-stage layouts, quick diagrams, and documentation drawings. For construction-grade BIM files, you still need dedicated CAD software.
Does any data leave my machine?
No. All drawing and export processing runs entirely in your browser. Nothing is sent to a server. Drawings are stored locally in browser IndexedDB.
